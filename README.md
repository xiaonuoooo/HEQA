# HEQA: Knowledge-Guided Hierarchical Video Quality Assessment for Multi-View Echocardiography

This repository accompanies the manuscript:

**Knowledge-Guided Hierarchical Video Quality Assessment for Multi-View Echocardiography**  
Yinuo Fan, Baoning Liu, Zirui Wang, Xiaoyun Yang, Yuezhong Zhang, Mei Wu, Jia Mi, Yankun Cao, Zhi Liu, and Guangtao Zhai  
*IEEE Transactions on Circuits and Systems for Video Technology* (under review)

## Status

This repository currently serves as a placeholder to satisfy the code availability requirement. The full source code, trained models, and evaluation scripts will be made publicly available upon publication of the paper.

We are committed to releasing the code to facilitate reproducibility and further research. Please check back later or contact the authors if you have any questions.
